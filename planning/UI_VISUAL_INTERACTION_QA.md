# Aster Reader — 每个 UI PR 的可交付验收单

> 必须与 `docs/36_COMPLETE_UI_UX_SPEC.md` 的 Screen ID 一起使用。此文档用于代码审查，不代表已完成测试。

## 交付必需

- [ ] PR 标题包含 Screen ID、场景与真实实现状态；截图不是完成功能的替代品。
- [ ] 对应 `UiState/UiEvent` 已经可通过 FakeRepository 预览、通过 ViewModel 接入真实数据。
- [ ] 默认、空、加载、错误、权限失联、受保护（适用）状态都有截图和可用按钮。
- [ ] 所有视觉样式来自 `design.md`；没有局部自定义主色、按钮高度/圆角漂移。
- [ ] 动效来自 `AsterMotion`，能中断且系统动画设为 0 时仍可操作。
- [ ] 返回路径、搜索 query、滚动 offset 和 Locator 正确恢复。
- [ ] Android 12 与最新验证系统、手势/三键导航均无系统栏覆盖。
- [ ] Compact/Medium/Expanded、横屏/分屏/折叠（适用）已测试。
- [ ] TalkBack 可访问，触控目标 ≥48dp，字体 200% 不裁主操作。
- [ ] 受保护内容在认证前没有缩略图/书名/缓存/最近任务/通知泄漏。
- [ ] 失败按钮能真的重试、取消与撤销语义真实；危险动作有后果说明。
- [ ] 不在主线程做阻塞 IO/封面解码；性能在 Release 构建验证。
- [ ] 真实文件与格式测试通过，不把 FakeReader 的动画标为真实 Reader 完成。

## 重点录屏

1. 资料库卡片 → 详情 → Reader → 返回原位置。
2. 搜索展开、筛选、空结果和撤销。
3. Reader 缩放、翻页、进度滑块、系统返回手势。
4. 进入受保护作品前认证，以及后台锁定时立即遮盖。
5. 扫描大目录和加密任务的进度、取消、出错与恢复。
