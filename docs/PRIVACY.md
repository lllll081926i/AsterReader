# Aster Reader 隐私说明

生效版本：1.0.0；日期：2026-11-08。

Aster Reader 是本地优先的 Android 漫画阅读器。应用不要求注册账户，不内置广告、分析 SDK 或自动崩溃上传。

## 本地数据

应用在本机保存作品索引、元数据、书架、阅读进度、书签、笔记、阅读时长和设置。通过 Android 系统文件选择器访问用户授权的文件或目录。导入和扫描不主动删除原文件。清理缓存不删除漫画原件或阅读记录。

## 网络访问

- 用户使用 WebDAV 时，应用向配置的服务器发送账号认证、目录查询和文件下载请求。服务商可记录连接地址、时间和请求路径。默认要求 HTTPS；显式允许 HTTP 后，账号和内容可能以明文传输。
- 用户点击检查更新时，应用向 GitHub 查询本仓库的最新正式 Release。GitHub 可获得 IP 地址及普通 HTTP 请求信息。应用不会附带书库、WebDAV 凭据或保险库口令。
- 应用没有跨设备阅读进度同步、自动上传漫画或后台定时扫描。

## 保护与备份

访问锁只限制应用内访问，不加密外部原文件。保险库使用 Android Keystore、独立长口令和分块 AES-256-GCM 保存密文。WebDAV 连接凭据以 Keystore 保护的密文存于应用私有目录。

系统云备份关闭。用户主动导出的公开书库清单包含公开作品元数据、进度、书架和批注，不包含漫画文件、隐藏作品、保险库密钥或 WebDAV 账号。加密清单只是清单的口令保护版本。逐作品保险库密文导出包含该作品的密文内容，与清单导出分开。

设备密钥损坏、应用被卸载或应用数据被清除时，本机数据可能无法恢复。请在操作前自行保管原件、清单及已经验证的保险库密文导出文件和口令。

## 用户控制

可移除书库索引、书架、WebDAV 连接或可再生缓存。移除云端连接不删除服务端文件。卸载或清除应用数据会清除应用私有数据；外部漫画原件及用户选择位置保存的导出文件由用户自行管理。

问题反馈：https://github.com/lllll081926i/AsterReader/issues 。提交反馈时，请自行去除账号、口令、受保护标题、路径和漫画内容。
