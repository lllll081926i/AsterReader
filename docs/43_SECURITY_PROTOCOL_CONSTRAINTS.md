# 安全协议收敛约束

日期：2026-11-07。补充文档 11、19、23、25、32，纠正复审中发现的歧义，不将规划功能标记为已实现。

## 当前能力

应用 PIN 与系统认证用于访问门禁；隐藏作品仍使用原明文文件。当前不提供文件 Vault、恢复槽或密码学双因素解封。清数据/卸载会移除应用私有记录与持有副本；外部原文件仍可能存在。

敏感设置降级需新认证：关闭应用锁、系统验证、息屏锁定、防截屏和任务预览保护，或延长自动锁定时间。认证绑定待执行操作，120 秒过期；取消、重新锁定和进程死亡撤销待执行操作。系统成功回调不能自行重新创建认证尝试。

PIN v3：`v3:pbkdf2-sha256:iterations:saltHex:hashHex`；新凭据 PBKDF2-HMAC-SHA256、600000 次、随机 16 字节盐、256 位派生输出。解析验证长度和成本上限；v2 固定解释为 60000 次，旧 SHA-256 继续验证，成功输入 PIN 后升级。短 PIN 只作本机门禁，不用于备份或 Vault 恢复。

## 加密公开清单 v1（已实现范围）

只包含当前公开清单既有字段，不含隐藏作品、漫画字节或安全凭据。不是完整应用备份。明文上限 16 MiB，仅在内存处理，不写明文临时文件。

容器二进制顺序与字节数：magic `ASTERB01`（8）、PBKDF2 迭代次数（4）、随机盐（16）、随机 GCM nonce（12）、密文含 tag 长度（4）、密文与 128 位 tag。整数使用大端。整个 44 字节头作为 AAD。

PBKDF2-HMAC-SHA256 固定 600000 次，派生 256 位 AES 密钥；口令以 Java `PBEKeySpec` 交给平台实现，不 trim、不做 Unicode 归一化。创建要求 12–256 个 UTF-16 code unit；恢复 1–256，精确匹配。每次导出重新生成盐与 nonce。AES/GCM/NoPadding 一次性验证后才返回明文，再进入现有清单验证和恢复事务。拒绝未知 magic/成本、负数或超限长度、截断和尾随字节；密码错误与认证失败使用同类提示。

导出先在内存生成完整密文，再写 SAF 目标。写入失败可能留下不可恢复的部分密文，界面提示失败，不能宣称备份成功；不自动删除用户所选文件。恢复必须先验证整个 tag，随后解析并通过现有事务合并，不进行先写数据库后验口令的操作。

控制范围内的 byte/char array 在结束时清零。JCA、JSON、Compose 和托管运行时可能产生无法主动擦除的副本，不能承诺内存物理零残留。口令不进入日志、导航持久化或状态恢复；锁定取消任务并清除目标状态。

## 文件 Vault 实施前的强制约束

1. **认证槽**：先定义 Device Slot、Recovery Slot 的具体包装格式和权限。独立包装同一 Master Secret 表达 OR。AND 不能通过两个成功布尔值冒充；实现与测试就绪前不提供该选项。恢复槽属于独立应急入口，必须明确其是否绕过日常认证策略。
2. **Keystore**：显式定义认证类型和授权时限，用 KeyProperties 常量配置 key，不混用 BiometricManager 常量。StrongBox 不可用可回退普通 Keystore，不得静默移除认证要求；硬件能力须以 KeyInfo 为准。捕获永久失效，禁止新建空密钥覆盖仍有数据的旧保险库。
3. **KDF 与包装**：恢复槽需要独立盐、版本化成本和导入成本上限。规范密钥包装算法、IV/tag、vaultId、objectId、用途与密钥代次的 AAD；不同用途分离密钥域。轮换先验证新槽，再提交替换，失败保留旧槽。
4. **容器**：头部必须有确定字节编码、严格大小限制和认证覆盖。总长度、块数、块大小、对象 ID、版本与算法均需认证。明确空文件、完整块截断、尾块、EOF、整数溢出与多余尾部行为。按块验证不得宣称整文件已验证。
5. **nonce**：每个 DEK 下 nonce 不得复用；块号不能回绕。中断后改写优先创建全新对象代次与 DEK，不能复用旧 DEK/块号覆盖不同明文。头、元数据、正文和密钥包装使用独立密钥域或可证明互斥的 nonce 域。
6. **迁移日志**：分别记录创建、写入、完整校验、不可变对象发布、DB 提交和源清理状态。文件与 DB 没有共同事务，每个状态定义重启恢复动作。孤立对象在证明非唯一有效副本前不得自动销毁。
7. **删除源文件**：完整重读已持久化密文并校验全部 tag、逻辑长度和内容身份后才允许。删除前核对源仍是被迁移的版本；Provider 无稳定版本时重新核验或保留原件。删除不是物理擦除，云历史和其他副本不受此操作控制。
8. **会话撤销**：先遮盖，再撤销会话代次，取消解密、预取与渲染任务，关闭安全来源并释放缓存。旧回调不得把明文重新发布。后台迁移与用户认证绑定的密钥生命周期必须一致，不能在锁定后无限持有 Master Secret。
9. **元数据**：原路径与文件名默认敏感。标题、封面、批注、搜索历史、导航中的私密名称不能进入普通 DB、FTS、任务日志或共享磁盘缓存。公开壳只保存最小随机标识和必要状态。
10. **备份与恢复**：恢复口令只有配套密文、包装槽和元数据仍存在才有用。禁止明文秘密进入备份；允许认证包装材料进入用户主动加密备份。备份 manifest 与快照必须认证并保护敏感字段。修改口令不会让已流出的旧备份失效。
11. **防回滚边界**：GCM 不自动防御整库回滚或证明数据最新。需要防回滚时另立 ADR 说明可信状态来源；不能对纯离线存储作无依据承诺。

完整容器字段、跨引擎安全随机读取、任务恢复与上述故障测试未交付前，不开放“漫画文件已加密”的 UI。
