# 09 漫画格式支持矩阵

状态以当前运行代码及测试为准。

| 格式 | 解析与阅读 |
|---|---|
| ZIP / CBZ | 图片条目自然排序，支持 UTF-8 与旧中文 GB18030 文件名 |
| PDF 漫画 | Android PdfRenderer 按页渲染 |
| 图片目录 / 单张图片 | 目录页码索引、自然排序、采样解码 |
| RAR / CBR | Junrar；RAR5、密码归档暂不支持 |
| 7Z / CB7 | Commons Compress，串行读取 |
| TAR / CBT | 校验物理头与长度，支持 GNU/PAX 长文件名 |
| EPUB 图片漫画 | OPF spine 顺序；不提供小说文字排版 |

图片扩展名：JPG/JPEG/JPE/JFIF、PNG、WEBP、BMP、GIF、AVIF、HEIC、HEIF。实际解码能力由 Android 系统提供；动画只显示静态帧。不能将不含图片的 ZIP 当作漫画成功入库。

目录扫描与单文件导入共用扩展名和 MIME 类型识别。归档导入时自动生成所选页面封面；默认第 1 页。PDF 自动生成页面封面，散图目录生成首图封面。缓存丢失可补全封面。

损坏、密码保护或不支持的归档不写入成功记录。原文件保留。本地文件无固定大小上限，普通来源直接按需读取，不整本复制；不可寻址来源使用分块兼容副本。不承诺扫描 ZIP 内嵌套的 ZIP 漫画集合；图片位于 ZIP 子目录时正常识别。
2026-11-07 扫描补全：目录递归扫描；扩展名与 MIME 类型优先筛选，未知类型探测前 512 字节，导入时再次用文件头校验类型。支持根目录平铺图片 ZIP、Store/Deflate ZIP、无后缀与错后缀容器。单文档 URI 与目录授权 URI 按 authority/documentId 去重；保留隐藏状态与阅读记录。扫描结果分别显示新增、更新、已存在、忽略、失败与失联，并在命中隐藏作品时提示验证后查看；失败原因不包含隐藏作品名称或路径。部分 Provider 不支持 last_modified 时重试基础元数据。
