# 启动稳定性与云端书架

日期：2026-11-07。

## 问题与实施

- 首屏先发布默认页面、再异步恢复会话，导致启动跳页。设置、安全状态与有效导航改为顺序恢复，完成后才标记设置就绪；系统首帧等待该状态，避免主题未恢复时先绘制加载页。
- 导航尺寸最初为 0，后续通过状态回写触发内容重新布局。改用 `AsterNavigationLayout`，同一次测量先取得岛形 Tab 或侧栏尺寸，再分配内容和消息区域。保留岛形导航和原有转场。
- 首批查询尚未完成时不能将默认空列表作为空书库。首屏等待书库与书架首批结果，查询失败提供重试。解除订阅后重置就绪标记，恢复时重新执行访问检查。
- PIN 失败次数及设置读取移到 IO；启动书库不查询全部批注和来源清单，相关页面按需订阅。
- 书库仓库延迟到启动 IO 阶段构造。WebDAV HTTP/TLS 客户端仅在第一次云端请求时创建；本地启动和连接列表不初始化 TLS。阅读统计设置延迟到实际使用时读取。
- 封面复用现有 Coil 内存/磁盘缓存，复用 ImageRequest，取消本地封面渐显，使用 AsyncImage 减少列表子组合。保险库封面继续禁用磁盘和内存缓存。
- 移除作品列表发布中的固定 150 ms 等待，避免安全状态变化和首批结果排队。保留 conflate，阅读进度仍由原有机制节流落盘。

## 云端目录与书架

最多 50 个独立 WebDAV 连接，支持不同服务商与同一服务商的多个账户。选择目录后点击「加入书架」，扫描该目录和子目录，并按连接 ID 与目录 URI 生成稳定书架 ID。重复扫描复用书架，保留书架改名及排序；同名目录生成不同名称，不合并其他账户的漫画。

公开书架不自动收录隐藏作品。移除连接保留书架和阅读记录；云端文件不修改。目录映射只新增数据库事务逻辑，不修改数据库 schema。没有后台扫描或跨设备进度同步。

## 核验与测量边界

导航布局测试覆盖 API31/35 的底部导航、侧栏和无导航阅读区。导航恢复测试断言第一个就绪状态已包含恢复后的 Tab。WebDAV 回归覆盖多连接、同名目录、重复扫描和阅读记录保留。

API35 模拟器 Debug 冷启动基线见 `build/startup-before*.txt`：1202 / 2766 / 2402 ms。这些值在开发构建负载下采集，样本少且波动明显，只作为可复查记录，不据此宣称提速或耗电下降比例。优化后结果和最终核验结果在交付时补充。
