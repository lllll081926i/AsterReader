## 已实施

### 安全与真实性

- 系统锁屏凭据回调替换模拟身份验证。移除默认 PIN 和应用 PIN 校验接口。未请求、已取消或息屏后迟到的认证结果不能解锁。
- 启动设置加载期间和锁定期间阻断主内容。后台超时、息屏和手动锁定撤销授权。系统认证跳转具有独立状态。
- 接入 FLAG_SECURE、最近任务保护与系统备份排除规则。
- 锁定时过滤受保护作品、书架显示、批注、继续阅读与平板详情。孤儿批注默认隐藏。移除作品时事务清理章节与批注。
- 私密书架明确为入口访问锁，不宣称成员文件已经加密。
- 导入读取真实 SAF 元数据和页面数。取消、损坏文件和不支持格式不会生成成功记录。保留原 URI 和原文件。
- Vault、密文认证校验、加密备份和恢复密钥尚未实现。相关入口明确拒绝执行，不覆盖 URI、标记或报告假成功。旧加密标记不构成加密证明。

### 阅读、内存与资源释放

- 单会话复用临时文件、ZipFile/PdfRenderer 和自然排序页索引。去掉每页重复复制源文件和查询提供者版本；扫描更新来源版本后建立新会话。
- 临时复制采用 64 KiB 缓冲，单文件上限 512 MiB，可取消。失败与会话结束清理临时文件。
- CBZ 不把整个图像条目读成 ByteArray。先读取尺寸，再采样解码；单图像最多 32 MiB，目标不超过约 200 万像素。
- PDF 按需渲染，目标不超过 1200 × 1600。构造失败也关闭文件句柄。页面渲染失败释放尚未交给 UI 的 Bitmap。
- Bitmap LRU 预算为 24 MiB、堆预算十分之一、memoryClass 十分之一三者最小值，最低 2 MiB。内存不足时清缓存并降低采样重试一次。
- 用 Mutex 串行初始化和解码。淘汰缓存不 recycle 仍由 UI 引用的 Bitmap。
- 离开阅读、后台、锁定和 ViewModel 清理时提交最后进度并关闭会话。清理压缩包、PDF、临时文件、索引和缓存。页面进入后台后也清空 Compose 持有的图片结果，前台重新加载。
- Activity 注销息屏接收器。Repository 仅持有 Application 来源。清理协程在 ViewModel 最终释放资源后取消。
- 页面采用懒加载；页码目录使用惰性列表。未主动预解码额外页。双页封面、奇偶末页和模式切换共享真实页码映射。
- 滑块只在松手时跳页。音量键接入翻页。实现双指缩放、双击缩放和平移；删除未实现的自动裁边开关。
- 书签从数据库读取与增删。适配方式、封面单页、阅读方式和安全设置持久化。作品失效显示返回入口。

### 扫描、搜索、交互与省电

- SAF 目录真实枚举，广度遍历并去重，单次最多 10000 项。最多 2 个解析任务，待处理队列容量 4。只支持每个文件作为作品。
- 已知大小和修改时间均未变化时跳过重解析。提供取消，后台停止扫描；已成功导入的作品保留，仓库标为未完成，可重新扫描。
- 增加来源、阅读时间、添加时间与批注查询索引。导入事务重新读取用户状态，避免扫描覆盖并发收藏和进度；同 URI 并发导入不会生成两条作品。
- 搜索放到 Default dispatcher，输入防抖并可取消。批注所属作品使用 HashMap 查找，避免每条批注遍历全部作品。排序使用真实字节数和添加时间。
- 阅读进度每秒合并写入，离开与后台提交。查询订阅随生命周期停止；扫描期间限制作品列表刷新频率。
- 删除装饰性无限动画。导航提供标准点击语义，选中状态可访问。Reduced Motion 覆盖主要导航、弹层和阅读切换。
- 统一核心主题与颜色来源。实验 Material3 弹层封装在 designsystem。
- 不增加轮询、定时扫描、WakeLock 或后台解码。Release 开启 R8 和资源收缩。
- 停止跟踪 463 个 core 构建生成文件，磁盘构建产物保留。
