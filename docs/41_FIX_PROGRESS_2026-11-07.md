# 全量审查修复进度与紧凑布局验收

日期：2026-11-07。基准提交：510e281。对应原始审查报告 docs/40_FULL_PROJECT_AUDIT_2026-11-07.md。本记录区分源码修复、桌面自动验证和设备验收，不能据此宣称所有架构能力已完成。

## 本轮实现

- 标题统一 18sp/24sp，顶栏最小 52dp；设置行最小 52dp，触控目标 48dp；组间与内容尾间距 12dp。系统 Insets 单独处理。
- 主导航使用 64dp 内容区；宽窗口使用导航侧栏。导航占位按实际测量，页面不再叠加大块底部补偿。
- 设置首页仅保留四组分类。主题、阅读、统计、仓库、书架、标签、缓存、备份、诊断、关于使用独立页面。PIN 与锁定时间使用下一级页面。
- 作品信息、文件属性、封面和卷序使用独立页面；输入可随页面保存，键盘不会遮住最后一项；保存成功后才返回，放弃修改前确认。
- 详情底部操作区参与正常布局，大字体进度信息换行；空作者不占一行。空状态按钮允许换行。
- 删除索引和书架、清理缓存、导出与恢复有具体范围确认。普通设置说明和装饰性页脚已移除。
- 默认公开备份排除隐藏数据；恢复先校验、再事务提交，合并较新进度并去重批注。页索引和单本配置参与备份。
- 修复封面生成、来源替换、扫描计数与状态、本地阅读副本、缓存清理、单本阅读配置、平移保存、双页方向和后台统计等实际缺陷。
- PIN KDF 移出主线程，移除默认凭据和自创回退；失败计数和冷却跨进程保存。
