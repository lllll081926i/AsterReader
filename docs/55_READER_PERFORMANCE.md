# 详情预读与首次阅读性能（2026-11-08）

## 实施

- 详情页在前台预读当前阅读页，使用与阅读页一致的正常清晰度预算（默认约 250 万像素）。不生成低清预览，不进行两阶段解码，不建立磁盘预览副本。
- 点击继续阅读时交接同一本的在途任务、来源会话与位图。并发请求同一页共用解码门锁，避免重复初始化或解码。
- 离开详情、进入后台或锁定时取消预读。资源清理按顺序执行；后续预读及阅读请求等待旧清理结束，避免旧任务关闭新会话。
- 未授权、来源失联或远程 WebDAV 来源不自动预读。预读不修改阅读进度；失败不阻断详情，阅读页仍可重试。
- 同页同区域的较高像素预算缓存可满足较低预算请求；升级成功后淘汰较低预算缓存，不回收 UI 持有的 Bitmap。
- 图片尺寸索引保存在来源会话中。ImageBitmap 包装随 Bitmap 复用，减少绘制期间的分配。
- 保持上下独立 0～16 页预加载和原位图内存预算。数据库、Vault 格式与用户原件不变。
