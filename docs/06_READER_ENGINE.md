# 06 漫画阅读引擎

## 范围与分层

产品只处理漫画。Reader Shell 负责工具栏、页码、手势、返回和安全遮盖；Repository 负责 SAF、压缩包、PDF 和资源生命周期。Composable 通过 ViewModel 请求页面，不访问文件或数据库。

当前实现 CBZ 与 PDF 漫画。PDF 采用 Android PdfRenderer，只提供图像页阅读。其他漫画容器见格式矩阵，不提前承诺支持。

## 文件与解码

- SAF URI 是持久来源，不假定真实路径。
- 本地容器无固定文件大小上限。普通本地文件和可寻址 SAF 描述符直接读取，不建立整本副本。仅不可寻址的提供者使用 64 KiB 可取消流式复制；临时授权转持久副本仍用于避免授权失效。WebDAV 的下载预算独立管理。
- CBZ 使用 ZipFile 随机访问，不全量解压。最多索引 10000 个条目，页名按自然数字顺序排序。
- 单张压缩图像最多 32 MiB；先读取尺寸，再采样到不超过约 200 万像素。
- PDF 与漫画直接加载正常清晰度页面（默认约 250 万像素），不再生成低清预览或进行预览到高清的两阶段解码。详情页在前台预读当前阅读页，点击继续阅读复用同一会话与位图；尚未完成的同页请求共用解码门锁。
- 同页同区域的高清缓存可直接满足较低像素预算请求；不同清晰度共用解码门锁。升级成功后移除较低清晰度缓存，但不回收 UI 仍引用的 Bitmap；失败不移除已有缓存。整页与不同区域条带的缓存严格隔离。
- 普通图片优先在同一条有界缓冲流内读取尺寸、回退并解码像素；文件头超出缓冲时才重新打开。图片尺寸索引属于当前来源会话；同页缩放或清理位图后重读只解码像素，不重复打开来源读取尺寸。换书或关闭来源后尺寸索引随来源释放。
- 同一会话复用文件、ZipFile/PdfRenderer 和条目索引。初始化与来源切换串行化，PDF 解码串行化；ZIP 和目录最多同时解码两页。当前页请求优先于尚未开始的预取，预取等待时不持有来源租约。
- 目录扫描只登记文件信息，不打开 PDF 或压缩包，不生成封面。详情预读或首次阅读时建立页数与目录，并与页面渲染共用同一来源。公开作品缺少封面时复用已解码的封面页生成缩略图，不额外解码或批量补图。单文件导入仍执行内容校验。
- Bitmap LRU 上限为 96 MiB、进程堆预算的六分之一、设备 memoryClass 的六分之一三者最小值；最低 4 MiB。内存不足时清缓存并降低采样后重试一次。
- 阅读设置提供上下独立 0～16 页预加载，默认向上 3 页、向下 6 页，优先处理滚动方向。预取受设备内存预算约束，给当前页保留空间；不运行后台轮询或常驻扫描。LRU 淘汰不回收仍由 UI 引用的 Bitmap。

## 页码与交互

单页、横向 LTR/RTL、条漫、双页使用相同的真实页码。封面可独立成页。双页必须覆盖奇偶末页；切换模式保留目标页。滑块只在松手时提交跳页。缩放支持双指、双击和平移。

页加载失败提供重试。取消请求不显示为失败。受保护文件不得交给普通文档渲染会话。

## 生命周期与进度

阅读进度按一秒合并写入。离开阅读、进入后台、锁定和 ViewModel 清理时提交最后进度并关闭会话。关闭时释放 PDF、压缩包、临时文件、索引和缓存。内存压力通知清理缓存。

Locator 仅保留作品、资源、页码、进度和时间信息。书签按作品与页码保存。扫描只更新来源信息，不覆盖用户收藏和阅读状态。

## 安全边界与后续项

普通漫画临时文件仅用于随机读取。Vault 必须经过独立安全来源，不得复用普通明文临时文件链路。目前真实 Vault 未实现，受保护文件拒绝打开。

区域解码、触点中心缩放、条漫精确 offset 恢复和设备性能基准仍需后续实施与验收。不得将当前采样解码称为完整分块解码。
