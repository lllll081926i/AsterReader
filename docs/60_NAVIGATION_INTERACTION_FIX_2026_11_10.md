# 返回与阅读恢复修复（2026-11-10）

用户本轮确认恢复预测性返回，覆盖此前关闭要求。本次按 MD3 skill 的导航审查项修复返回交互，不代表整份应用审查报告中的问题均已解决。

## 实现

- Manifest 启用系统预测性返回，导航容器使用现有 Activity Compose 的 PredictiveBackHandler，不升级依赖。
- 当前页面跟随左右边缘手势进度缩放、位移和收圆角。取消复原，完成才回退；手势期间路由已变化时不再提交旧路由的回退。
- 页面返回不追加淡入。前进及主标签切换保留统一动效。Reduced Motion 禁用空间动画，API 31 与三键返回直接完成回退。
- 只组合当前页，不同时运行上一页的阅读、网络和解密会话。手势背景使用不透明 Monet surface，当前实现不展示上一页内容预览。
- 各主标签和在栈页面通过 SaveableStateHolder 保留滚动及局部状态。出栈清理已放弃的状态，避免再次进入恢复旧表单。
- 受保护会话禁用页面状态持久化；应用锁定沿用原有授权和导航清理。批量选择退出不执行页面空间动画，局部编辑和弹窗仍优先消费返回。
- 详情“继续阅读”传入空初始页，恢复完整阅读视口。章节、书签和明确选页保留跳页行为。
