# 设置、阅读配置与关于页调整

## 实现

- 设置首页移除默认阅读、诊断与帮助。旧导航恢复时过滤这两个页面。
- 原默认阅读的翻页、缩放、封面单页和音量键翻页全部进入漫画阅读设置。
- 手机和平板均从阅读页进入独立全屏设置页面，共用 `ReaderSettingsContent`。本书与默认分开选择；恢复默认仅清除当前书覆盖，不清除其他作品设置。亮度、音量键翻页保留全局保存方式，状态条保留本次阅读状态。
- 翻页选项在正常宽度和字号下采用两列，缩放使用等宽分段按钮；窄窗口与大字体保留单列回退。选项最小触控高度 48dp，统一 Monet 底色，仅高亮选中项。没有深浅交替。其他面板保留上拉交互。
- 右下阅读状态条去掉边框与阴影，背景不透明度 42%，字号 8sp，横向/纵向内边距 4dp/1dp。
- 设置标题和选项缩短；删除重复说明。保留清理缓存、公开备份范围和安全能力的必要说明。
- 关于页显示实际构建版本、系统要求、支持格式和隐私边界。开源许可具有独立列表与详情页，支持加载、重试和无效条目提示。
- 构建任务读取实际运行依赖及父 POM，生成许可信息。字体许可全文随包提供，详情无需网络；外部许可来源链接需要浏览器和网络。

## 修改模块

- `app`：设置、阅读设置、关于页、许可 Repository、ViewModel、构建资源生成任务及回归测试。
- `core:designsystem`：补充共用控件间距令牌。
- `design.md`、UI 规格和页面矩阵同步当前入口与层级。

## 数据与安全

没有数据库结构变更或数据迁移。没有重置应用、阅读记录、PIN 或作品配置。保留系统验证、PIN 校验、禁止截屏和锁定内容遮盖。

隐藏作品仍是应用内访问控制，原漫画文件未加密。公开清单备份不包含漫画文件或隐藏作品。本次没有将文件 Vault 标记为完成。

## 核验边界

### 顶部留白实测

在 API35 模拟器（720×1280、density 2）检查旧包设置页：系统状态栏为 48px（24dp）；标题文字边界 y=70..122px；标题栏范围约 y=48..144px（48dp）；首组标签从 y=156px 开始，与标题栏底部相距约 6dp。公共根布局没有顶部补偿 Padding，页面各消费一次状态栏 Insets；当前证据未发现顶部 Insets 重复叠加。标题文字上方可见距离包含系统状态栏和标题栏内部居中空间。标题栏保留 48dp 触控目标。阅读设置弹出面板移除拖动条占位，保留关闭按钮。

用户截图进一步显示：应用选择深色主题后，状态栏仍使用黑色时钟和图标。根因为 `enableEdgeToEdge()` 默认根据系统明暗决定图标颜色，没有跟随应用独立选择的主题。现由 Compose `SideEffect` 同步实际应用主题到状态栏、导航栏图标。此修复改善顶部黑色空区的视觉问题，不虚报减少状态栏本身的物理高度。新增 API31/API35 系统栏图标切换测试。

用户随后明确浅色同样过高：实际密度调整采用统一 40dp 可见标题栏，替代旧包 48dp。标题统一为 18sp/22sp，图标维持 18dp，正文同步上移。公共标题栏局部取消 Material 的额外布局占位，Compose 输入层仍使用系统默认的 48dp 最小触控扩展，未修改 ViewConfiguration。测试核验可见高度、触控边界，以及可见按钮上方 2dp 的实际点击。依据：[Compose 默认无障碍行为](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)。

API31 与 API35 使用 Robolectric 核验选择、布局、200% 字号和浅深色；不能替代真机 TalkBack 与系统交互验收。API37 使用 SDK 编译，当前模拟器为 API35，API31/API37 尚无本轮手工设备验收。
