# 阅读画布事件与持续视口监听

## 问题与实施

此前每个页面在 onGloballyPositioned 回调中计算 positionInRoot 并写入 Compose 状态。连续滚动时，即使水平位置不变，也会反复执行坐标计算。画布根节点同样使用状态缓存全局范围，供稍后发生的触摸使用。

PublicationPageCanvas 现在通过 onPlaced 保存布局引用，不将位置写入可观察状态。触摸发生时才查询当前坐标与画布范围。中央点击范围仍取整幅画布中央一半，双页阅读的左右点击方向仍按整幅画布判断；系统手势边缘继续使用真实触点坐标检查。

原来的单页缩放上报、分页视口监听和连续滚动视口监听，将缩放和平移放在 LaunchedEffect 的 key 中。每次手指移动都会取消旧监听并创建新协程；分页监听还会再次发送同一页的换页通知。

本轮改为在持续的 snapshotFlow 中观察缩放、平移与滚动位置，使用最新回调上报。分页首次仍上报规范化后的双页起始页；后续仅在页码变化时通知换页。同页缩放和平移继续保存。连续滚动的程序跳转结束后恢复上报当前视口，避免恢复监听依赖用户再次拖动。

跨页时，单页 resetToken 只随该页进入或离开当前页而变化，其余已组合页面不再因当前页码变化重建手势。退出或切换作品仍按原生命周期释放状态。未修改清晰度、预加载页数、内存预算、工具栏显隐或导航动画。

## 验证

新增分页和上下滚动两种模式的原生图形回归：双击后比例为 2.2，触点产生的平移会保存；继续单指平移后比例保持 2.2、平移达到边界。整个过程不重复发送换页通知。回归在 Robolectric API31/35 执行。

继续执行 ComicPageCanvasTest 和 ReaderZoomTest，覆盖中央即时开关、滚动不误触、双页整幅热区、RTL 点击方向、缩放重置、缓存首帧高度、页内恢复、直接跳转到第 8000 页与完成状态。定向日志为 build/reader-canvas-targeted.log，完整日志为 build/reader-canvas-verification.log。

完整核验通过：399 项测试，失败、错误、跳过均为 0；Release Lint 为 56 条警告、0 错误；Debug APK 与设备测试源码编译成功。已检查自动生成的 API31 短图截图（app/build/ui-review/cached-short-page-api31.png）：图片按比例贴顶，下方保留画布背景。该截图使用测试夹具，不代表真实漫画的完整视觉验收。

## 影响与验收

仅修改 app 的阅读画布及测试，并同步设计规范和任务矩阵。无数据库迁移、加密格式、依赖或版本号变化。本轮不发布。

API31/API37 真机尚未验收。自动化覆盖触摸行为和保存结果，不作为真机帧率证据。后续仍需在 Release 真机上核对超大漫画的连续滚动与缩放帧时间。
