# 25 应用锁 / 局部锁 / 加密 UI 规范

## 1. 设置页

新增“隐私与安全”分组：

```text
隐私与安全
  应用锁                     [开关]
  解锁方式                   系统屏锁 / 应用密码 / 任一 / 双重
  自动锁定                   30 秒
  屏幕关闭时立即锁定         [开]
  最近任务隐藏内容           [开]
  受保护内容禁止截图         [开]
  保险库
  恢复密码                   已设置 / 未设置
  验证保险库
```

## 2. 单本书菜单

```text
继续阅读
加入书架
编辑信息
加密并上锁     ← 主安全动作
仅添加访问锁   ← 高级选项，明确“不加密原文件”
导出/移出保险库
删除
```

## 3. 批量

多选后：

- 加密并上锁
- 添加访问锁
- 加入书架
- 标签

加密为后台任务，有总进度 + 每本状态。

## 4. 文件夹/仓库

仓库设置：

```text
保护策略
  不保护
  新增内容自动加密到保险库
  仅进入仓库时认证
```

“新增内容自动加密”要提示：原目录中的新文件会被复制到 Vault；是否删除源文件由策略单独设置。

## 5. 书架

书架设置：

```text
书架访问锁
批量加密该书架中的内容
```

两者分开，防止用户误以为锁书架=文件加密。

## 6. Locked Card

认证前：

- 不显示真实封面
- 不显示书名
- 不显示作者
- 显示统一锁图标、数量或“受保护内容”

## 7. 解锁

优先调用系统 BiometricPrompt。  
应用密码作为用户选择的替代或第二因素。

失败：

- 不清空页面重载造成闪烁。
- 不显示“密码错误次数”之外的敏感信息。

## 8. Reader 中重新锁定

若 App 在 Reader 中被锁：

```text
Reader -> immediately cover content -> AuthGate
```

不要先做退出 Reader 动画再遮盖内容。

解锁成功后可回到原 Locator。

## 9. 文案词汇表

统一：

- App Lock：应用锁
- Vault：保险库
- Encrypt & Lock：加密并上锁
- Access Lock：访问锁
- Device Credential：系统屏锁
- Recovery Password：恢复密码

禁止同一功能在不同页叫“私密模式 / 隐藏模式 / 安全锁 / 加密锁”等多个名字。
