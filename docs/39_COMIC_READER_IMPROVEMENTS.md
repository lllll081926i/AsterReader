# 漫画核心体验改进

## 实施提案

范围：阅读页内位置与缩放恢复、单本设置、真实封面与封面页选择、局部高清解码、触点缩放与边缘手势、扫描来源状态、ZIP 与图片目录、系列分卷与下一卷。

改动模块：app 的 Repository、渲染会话、ViewModel、Reader 与仓库 UI；core:database 增加阅读状态和图片目录页索引，作品增加来源与卷序信息；core:model 增加规范化阅读视口。设计与格式矩阵同步。

开发数据库采用独立的新库，不迁移旧开发数据，不删除用户源文件。受保护内容不得生成普通封面或进入普通解码链路。

## 验证计划

验证页内位置、缩放和单本设置持久化；真实封面与容量限制；区域像素解码；图片目录自然排序与重扫；删除/失联/授权失败不清空记录；扫描取消不标记全库失联；手动关联保留书签；系列顺序与连续阅读；完整单元测试、Lint、Debug 和 Release R8。

API 31/API 37 手工状态与实际结果在实施结束后记录。设备未测量的指标不标为达标。
