# 直接跳页与超大文件读取优化

## 实施范围

仅修改 app 阅读页、阅读画布与解码会话。进度条拖动时保留预选，松手时直接定位目标页顶部，不滚过中间页面；新增跳转序号，支持选择当前页时回到顶部。正常手指滚动保持原行为。跳转后的尺寸校正一旦观察到用户继续滚动即放弃，避免慢页加载完成后强行拉回目标页顶部。

大图集预加载利用会话内已知原始尺寸与采样率估算位图占用。近页不能让出的空间不足时，不再重复读取已知放不下的远页。首次未知尺寸仍需实际读取；估算不能替代实际缓存准入检查。未进入缓存的远页不再调用 prepareToDraw，减少无用绘制准备。

图片流每次读取或跳过数据前检查任务状态。取消旧页读取后，在下次读取边界抛出 InterruptedIOException，并由解码任务恢复协程取消语义。解码返回后再次检查取消，不将已取消任务的位图写入缓存。关闭流仍释放归档条目资源。不承诺中断已经提交的CPU解码或PDF原生渲染。

## 验证

增加一万页场景直接跳到第8000页的回归，检查不加载跨越的中间页；增加当前页重新选择回到顶部的回归。缓存回归增加重复预加载检查，确认已知放不下的远页不重复打开。流回归验证取消后单字节、缓冲读取和跳过均停止，关闭仍释放来源。

最终执行 `gradlew.bat testDebugUnitTest :app:lintRelease :app:assembleDebug :app:compileDebugAndroidTestKotlin --console=plain` 成功。386项测试全部通过，0失败、0错误、0跳过。Release Lint为56条警告、0错误。日志为 build/reader-direct-seek-verification.log，定向日志为 build/reader-direct-seek-tests.log。

新增原生解码取消回归确认：流打开后取消，底层读取次数为0，关闭次数为1，缓存字节为0，会话可正常关闭。Native Graphics测试的解码器会在取消输入时输出 InterruptedIOException 与 incomplete input 诊断；该回归断言协程取消与资源释放，不以隐藏诊断实现通过。

自动化覆盖Robolectric API31/35。API31/API37真机滑动、超大ZIP实际读取耗时仍待设备验收。无数据库迁移、加密格式、扫描流程、依赖或版本号变化。不发布。
