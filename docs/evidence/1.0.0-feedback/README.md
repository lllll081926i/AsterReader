# 阅读反馈修复验收

截图由 API31/API35 Robolectric 渲染生成，使用测试创建的漫画文件，不含用户内容。

- `reader-chrome-hidden*`：进入阅读时隐藏上下工具栏，截图包含加载占位。
- `reader-compact-monet*`：中央点击后的工具栏与正常阅读内容。
- `reading-preload-sixteen*`：上下预加载各设置为 16 页。

触摸回归覆盖抬手即响应、连续点击不补切换、加载与短图留白点击、滚动、双指、长按、取消触摸、两侧双击缩放、RTL 翻页和双页热区。返回回归覆盖手势中不切页、取消不回退、完成只回退一次。
