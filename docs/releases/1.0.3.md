# Aster Reader 1.0.3

本次版本面向 **UI 动效质感、导航手势连贯性与高性能渲染** 进行了系统性升级：全面升级 Jetpack Compose / Material 3 Expressive 与 Navigation 3 底座，补全页面切换、预测性返回、封面共享元素与底部悬浮导航滑动胶囊效果，同时通过 RenderNode 图层延迟与 `Modifier.Node` 零分配设计保持列表滚动与阅读切换的流畅响应。

## 更新内容

### 导航转场与预测性返回
- 升级至 **Compose BOM `2026.11.01`**（Material 3 `1.5.0`、Compose Animation `1.13.0`）、**Navigation 3 `1.2.2`**、**Material 3 Adaptive `1.3.0`** 与 **Navigation Event `1.2.0`**，并接入 `MotionScheme.expressive()`。
- 重构主导航容器为 `NavDisplay` + `SharedTransitionLayout`，全面消除此前页面硬切现象：
  - 普通入栈与返回采用对称的 MD3 Shared-Axis X 空间过渡；
  - 支持系统 **预测性返回（Predictive Back）** 手势跟手缩放、平移与圆角收窄，平稳显露底层非受保护页面，手势取消可完整复原，不会误触发二次退栈；
  - 阅读器进入/退出按作品实例 `bookId` 隔离会话资源与回收生命周期，确保快速返回或连续切书不误伤新会话；
  - 锁屏 / 快速认证门禁接入独立淡入缩放解锁过渡，解锁前严禁泄露或参与共享元素。

### 底部导航滑动胶囊与内容联动
- 为底部悬浮导航栏新增 **弹簧胶囊滑块（Draw 阶段零重组绘制）**，随 Tab 切换平滑横移，并与图标微缩放、选中色彩过渡及双向页面内容滑入淡变保持同步；支持 RTL 布局、隐藏统计页签时的动态对齐，以及高缩放字体环境下的自适应布局。

### 共享元素、微交互与性能保障
- 打通 **书库 / 搜索 / 书架 / 系列 → 作品详情** 的封面共享元素过渡，并严格加上可视区域门控（仅在屏项参与）与隐私隔离（隐藏/加密/缺失项及锁屏状态自动退出共享）；平板分栏右侧详情同步支持切换过渡。
- 重构按压回弹缩放（`asterCardInteraction` / `asterBounceClick`）与列表/搜索结果轻量显影（`asterContentReveal`）为纯 **`Modifier.Node` + RenderNode 图层实现**，消除 `Modifier.composed` 内存分配与逐帧重组开销。
- 新增 **根容器单点系统动效监听**（`ContentObserver` 监听 `ANIMATOR_DURATION_SCALE`），系统关闭动画后无需重启即刻降级为「减弱动效」，同时确保分页跳页、无限动效、共享元素与页面转场完整遵守无障碍偏好。

## 下载与安装

需要 **Android 12（API 31）及以上系统**。本次构建提供三个正式签名安装包：

| 安装包 | 适用设备 |
|---|---|
| `AsterReader-1.0.3-arm64-v8a.apk` | 大多数现代 Android 手机与平板（**推荐优先下载**） |
| `AsterReader-1.0.3-armeabi-v7a.apk` | 使用 32 位 ARM 运行环境的设备 |
| `AsterReader-1.0.3-universal.apk` | 包含全部支持 ABI 的通用包，不确定架构时选择 |

沿用项目正式签名，已安装 `1.0.0` / `1.0.1` / `1.0.2` 正式版的用户可**直接覆盖升级**，原有本地书库、阅读进度、笔记与保险库数据完整保留。版本为 `1.0.3`（`versionCode 6`），不涉及数据库结构或加密容器格式变更。
