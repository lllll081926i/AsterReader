# Aster Reader 1.0.1

本次更新集中改善漫画阅读性能与界面交互。

## 更新内容

- 进度条松手后直接跳到目标页顶部，不再滚过中间页面；选择当前页也能回到页顶。
- 优化大 ZIP / CBZ 和多图片漫画的读取、解码与预加载，减少重复加载和滚动时的空白过渡。
- 优先保留当前页和相邻页缓存，及时停止过期页面读取，减少快速跳页时的资源占用。
- 修复导入后封面自动生成和刷新，提高自动封面的清晰度。
- 按 Material Design 3 重做全局设置与阅读设置，恢复正常界面比例。
- 修复预测性返回、阅读位置恢复和相关切换交互。
- 调整底部导航岛宽度与按钮间距，保留随标签数量自适应。

## 下载

需要 Android 12 或更高版本。本次仅提供三个安装包：

| 安装包 | 适用设备 |
|---|---|
| `AsterReader-1.0.1-arm64-v8a.apk` | 大多数现代 Android 手机和平板，推荐 |
| `AsterReader-1.0.1-armeabi-v7a.apk` | 使用 32 位 ARM 应用环境的设备 |
| `AsterReader-1.0.1-universal.apk` | 包含上述两种 ARM 架构，不确定时选择 |

沿用正式签名，已安装正式版可直接覆盖升级，保留书库和阅读记录。版本为 1.0.1（code 4），不更改数据库或保险库格式。

问题反馈：[GitHub Issues](https://github.com/lllll081926i/AsterReader/issues)。
