# Aster Reader 1.0.0

Aster Reader 的第一个正式版本。一款面向 Android 12 及以上系统的本地漫画阅读器，提供系统 Monet 动态色、离线书库、漫画阅读、WebDAV 只读来源与独立加密保险库。

## 主要功能

- **本地书库**：通过系统文件选择器导入文件、添加目录与递归扫描；支持书架、收藏、标签、系列、搜索和失联来源重新定位。重新定位保留作品身份、阅读进度与批注。
- **漫画阅读**：支持 CBZ/ZIP、RAR4/CBR、7Z/CB7、TAR/CBT、PDF 漫画、图片目录和单图。图片型 EPUB 按图片阅读；不提供文字书重排、MOBI 或 DRM 支持。
- **阅读操作**：纵向滚动、分页、双页、独立翻页方向、双指与双击缩放、单本设置、页码定位、书签和笔记。保存阅读进度、已读状态及本机阅读时长。
- **WebDAV**：提供坚果云、Nextcloud、群晖 NAS 与自定义连接预设；支持多账户、连接测试、目录浏览、文件阅读与目录加入书架。连接凭据由 Keystore 加密保存。
- **隐私保护**：应用 PIN、系统认证、隐藏作品与访问锁；保险库支持逐作品加密、长口令、密文读取、完整性校验、密文导出与恢复。
- **备份**：导出或合并恢复公开书库 JSON 清单，也可使用口令加密清单。清单不包含漫画文件；逐作品密文导出在保险库相关入口单独执行。
- **界面**：浅色与深色 Monet、悬浮导航、宽窗口侧栏与双栏详情、减少动效设置及基础读屏语义。

## 本次发布前修复

- 更新 RAR 解析库至 junrar 8.1.2，覆盖已知 RAR VM 循环、扩展时间头和流式完整性失败问题。
- 为 EPUB XML 增加展开字节、节点、深度及整本累计预算；解析失败时使用受限的图片回退路径，并释放失败的归档句柄。
- 新建书架及保存笔记在持久化成功后才关闭或清空输入；失败时保留输入。统一书架管理入口，禁用无效的边界排序操作。
- 批量书架选择支持滚动和空状态；扩大筛选及阅读操作触控区，补充筛选选中语义。
- 修正阅读章节按钮的跳页文案、返回按钮文案和笔记保存文案；密文属性不再展示内部来源 URI。
- 没有真实章节时明确前后跳 10 页，并禁用页首/页末无效操作；页码目录按可见项创建，避免长漫画一次分配全部目录对象和逐页扫描。
- 修正短页滚动到底部时的页码回报；读取已保存位置前不写入初始进度，恢复不覆盖已发生的跳页。
- 随包提供运行库和字体的离线许可全文，并校验各安装包的签名、版本、ABI 和 16 KB 对齐。

## 下载与安装

最低要求：**Android 12 / API 31**。无需注册账户。

| 附件 | 适用场景 |
|---|---|
| `AsterReader-1.0.0-universal.apk` | 不确定设备架构时选择；包含全部四种 ABI |
| `AsterReader-1.0.0-arm64-v8a.apk` | 大多数现代 Android 手机和平板，推荐优先选择 |
| `AsterReader-1.0.0-armeabi-v7a.apk` | 使用 32 位 ARM 应用环境的 Android 12+ 设备 |
| `AsterReader-1.0.0-x86_64.apk` | 64 位 x86 模拟器或相应设备 |
| `AsterReader-1.0.0-x86.apk` | 32 位 x86 模拟器或相应设备 |
| `AsterReader-1.0.0.aab` | 应用分发平台使用，不能直接点击安装 |
| `SHA256SUMS.txt` | 当前批次附件的 SHA-256 校验值 |
| `release-certificate.txt` | 签名证书及验证信息 |
| `THIRD_PARTY_NOTICES.txt` | 第三方运行库、字体许可与声明 |
| `PRIVACY.md` | 本版本隐私说明 |
| `RELEASE_NOTES.md` | 可离线保存的版本说明 |

下载一个与设备匹配的 APK，允许当前下载应用安装未知来源应用后安装。所有 APK 与 AAB 使用同一长期正式签名。版本名为 `1.0.0`，`versionCode=3`，高于开发包的版本代码。已安装同签名开发正式包时可覆盖升级；Debug 包签名不同，不能直接覆盖。不要为了安装而直接卸载唯一保存了数据的旧包；先验证备份和保险库密文导出。

## 使用边界与已知限制

- 单文件上限 512 MiB。WebDAV 下载后阅读，暂不支持自动上传或跨设备同步。
- 建议使用 CBZ 或 PDF；暂不承诺 RAR5、加密归档和 DRM 支持。
- 访问锁只隐藏入口。保险库加密不会删除外部原件；备份清单不包含漫画正文。请保管好口令和密文导出，避免密钥丢失后无法恢复。
- 首版仍会持续完善设备兼容性、大字号与无障碍体验。遇到问题欢迎反馈。

## 数据与反馈

本次不更改数据库 schema、保险库容器格式或用户密钥，不执行破坏性迁移，不删除漫画原文件。应用无广告、无分析 SDK、无自动崩溃上传；网络访问由 WebDAV 操作或手动检查更新触发。

反馈问题请附系统版本、设备架构、操作步骤和脱敏后的错误信息：[GitHub Issues](https://github.com/lllll081926i/AsterReader/issues)。请勿提交密码、密钥、受保护书名或漫画原文。
