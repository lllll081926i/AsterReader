# Aster Reader 1.0.4

本次版本聚焦于 **阅读器交互细节打磨、图像与归档解码性能提升、以及全局 Compose 渲染与内存治理**：全面审查并优化了解码管线、超长条漫/PDF 硬件纹理安全边界、加密容器随机访问与主线程高频状态开销，带来更顺滑、稳定且低占用的阅读与浏览体验。

## 更新内容

### 解码管线、归档读取与内存优化
- **超长条漫与 PDF 纹理安全防护**：完善像素采样与单边尺寸上限约束（`4096px`），避免极长条漫或极端宽高比页面触发 GPU 纹理越界黑屏或异常；保留原始尺寸元数据，放大查看时自动衔接高清区域条带解码。
- **高清区域解码并发与回收治理**：将 `BitmapRegionDecoder` 初始化移出同步锁区间，降低放大漫游时的锁竞争；取消/切书/系统低内存回调（`trimMemory`）时同步释放解码器资源。
- **加密保险库与本地归档加速**：
  - 加密容器（`VaultComicArchive`）读取 ZIP / CBZ / EPUB 时跳过逐条目本地头扫描，显著缩短大型加密漫画的首次打开与随机解密延迟；
  - TAR 归档切页改用 `FileChannel.position` 实现 O(1) 偏移定位；ZIP 归档补齐条目上限防护；各归档 `pageNames` 缓存为不可变列表；
  - 单文件导入 ZIP / CBZ 优先走可寻址 SAF 直读通道，减少大文件导入时的临时整本复制；翻页热路径对已索引作品跳过全局索引互斥锁；
  - 修复保险库目录流与 PDF 代理描述符异常路径下的潜在资源泄漏；
  - 封面重建与换页后自动清理旧缓存文件，并为 Coil 显式限定内存缓存配额且对保险库封面按目标控件尺寸动态采样解码。

### 交互体验与 Compose 渲染性能
- **阅读器操控与进度反馈优化**：
  - 拖动底部进度条时实时预览目标页码与百分比，松手精准跳转；
  - 上一话 / 下一话、前后 10 页及目录（底部抽屉与平板侧栏）跳转同步触发页顶精确定位，并兼容翻页模式；目录列表支持稳定键值与默认定位当前章节附近；
  - 稳定化画布加载回调减少不必要重组，放大状态与高清条带采用 `FilterQuality.Medium` 提升缩放清晰度。
- **全局低开销交互与状态治理**：
  - 搜索输入对导航会话持久化增加 300ms 防抖节流，消除逐字输入时的连续磁盘写入；
  - 缓存首页统计、书架拼图列表、标签聚合与导航目的地列表，减少高频重组时的集合重复分配；
  - 将锁屏 PIN 错误抖动动效收敛至 `AsterMotion.errorShakeSpec`，确保设计系统动效规范一致。

## 下载与安装

需要 **Android 12（API 31）及以上系统**。本次构建提供三个正式签名安装包：

| 安装包 | 适用设备 |
|---|---|
| `AsterReader-1.0.4-arm64-v8a.apk` | 大多数现代 Android 手机与平板（**推荐优先下载**） |
| `AsterReader-1.0.4-armeabi-v7a.apk` | 使用 32 位 ARM 运行环境的设备 |
| `AsterReader-1.0.4-universal.apk` | 包含全部支持 ABI 的通用包，不确定架构时选择 |

沿用项目正式签名，已安装 `1.0.0` / `1.0.1` / `1.0.2` / `1.0.3` 正式版的用户可**直接覆盖升级**，原有本地书库、阅读进度、笔记与保险库数据完整保留。版本为 `1.0.4`（`versionCode 7`），不涉及数据库结构或加密容器格式变更。
